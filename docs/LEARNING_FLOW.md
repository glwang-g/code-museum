# 阅读、对比与实验的连贯路径

2026-11-11，本轮沿用正式版式推进三项收敛：学习入口、任务上下文和实际耗时基线。完整馆藏、历史证据边界、59个执行语言节点及固定原版 `/classic/` 沿用原有范围。

## 入口与手机点击

“语言对比 / 学习导览 / 出处与说明”在各页保留为固定的学习导航。手机的展厅、全馆、实验室仍在底部；原生滚动定位预留底栏与安全区，页脚链接不会落到底栏下面。键盘方向键跳过当前隐藏的探索页签；当前页签隐藏时仍保留一个可聚焦入口。

新增 `#guides` 展示全部5条原有路线、27个步骤，可展开查看路线内容；同一条活跃路线显示“继续导览”，只有明确选择“从头开始”才清零当前步骤。原练习真实输出核对和本机完成记录继续使用原控制器。

页脚已在绑定逻辑前解析。换页滚动同步完成，避免延迟滚动移动用户刚要点击的导览按钮。手机验收使用真实鼠标/键盘事件与 `elementFromPoint` 命中检查；Chrome手机布局模拟不等于Safari触控板实机验收。

## 同一个题目，不丢草稿

阅读页的“同题练习”选择器、对比两侧的阅读/实验入口、实验台的了解/对比按钮共同传递语言和题目。11门同题语言、5类题目沿用既有教材；支持的语言优先保持上次对比伙伴，否则使用固定伙伴。仅比较任务表达，不据此添加历史影响关系。

“继续这个任务”和对比转入实验室保留该语言与题目的草稿，不自动执行。自由草稿往返阅读继续保留default上下文；预设对比明确标为馆内教材，只有选择馆内任务时才切到对应题目，不将任意自写代码冒称为同题教材。“把这段示例带入实验室”是明确替换动作，使用原有备份，可以在代码工具中撤销；展厅试运行同样导入眼前的原样代码。尚无同题教材的语言明确提示范围，可打开已有对比，不虚构教材。

阅读地址增加可选 `topic`，旧阅读书签仍可用。刷新、分享和前进后退保留公开任务上下文；URL不包含代码、标准输入、预期行为、模型输入或执行会话凭据。导航、载入示例和切换结果页签均不调用模型。

## 实际耗时与复查方式

先建立实际基线，再对照同一份代码的加载方式。新增有序 `defer` 在受控对照中反而变慢，因此撤回这项调整，继续原脚本加载顺序；主题脚本仍提前执行。页脚绑定问题通过将绑定脚本放到页脚后解决。没有增加运行时预下载、隐式模型调用或常驻容器。

可在本机按以下方式重复检查，不下载新依赖：

```sh
npm test
npm run build
# 另一个终端启动本地预览：PORT=4191 npm run preview
npm run learning:browser
npm run site:browser
npm run platform:measure -- --origin http://127.0.0.1:4191 --output tmp/platform-local.json --samples 3
```

`platform:measure`默认只测页面。只有显式添加 `--executions` 才点击运行五份已知输出42的公开小程序；`--model`才点击一次模型检查，随后验证浏览器同稿缓存不再请求。`--fresh-model`给固定程序追加时间注释，单次识别未命中服务端缓存的等待；普通重复测量允许服务端缓存，但记录实际 `cached` 字段。不会运行模型生成的候选代码。

指标区分：首次新浏览器加载/刷新缓存、首份本地解释器资源准备/已就绪执行、远端排队/编译/运行/环境总计、模型请求/服务端缓存/浏览器缓存。结束点是界面结果DOM更新；不是GPU实际呈现时间。每个宽度3个首开样本，每门执行3次，只报告中位数和范围，不称为p95或并发压测。新浏览器不代表服务器/CDN也冷启动；手机为390px布局模拟，没有网络/CPU节流。报告仅记录版本、计时、状态及测试程序哈希，不记录用户代码、输入、输出、意图、Cookie或任务ID。

正式站更新前的基线见 [发布前测速](../data/audit/platform-baseline-before.json)。本轮真正需要关注的差异是：Python**显式选择本地模式**时首次要下载和初始化Pyodide，后续会复用；正式站Python默认仍为远端。Groovy每次独立环境中的JVM启动与脚本编译算在运行阶段，后续请求不承诺提速。模型未缓存的等待与命中缓存必须分别看，不能混成一个“模型速度”。发布后同源复测结果另记，不用本地回环结果推断公网加速比例。
