# 身份别名批次 3：ColdFusion 与 CFML

日期：2026-10-11

核读 Adobe ColdFusion 官方文档：

- URL：`https://guides.adobe.com/coldfusion/en/docs/develop-coldfusion-applications/introducing-coldfusion/about-coldfusion.html`
- 完整响应 SHA-256：`e8bcce4a4646981132c4ac7ca78da1cbb4bddce5a77e2d6bd2a19ecd391117af`
- 原文：“Adobe ColdFusion is a rapid scripting environment server ... ColdFusion Markup Language (CFML) is a tag-based scripting language.”

将 `coldfusion` 的 GitHub Linguist 别名 `cfm`、`cfml`、`coldfusion html` 从等价检索别名中排除：ColdFusion 是平台/服务器，CFML 是独立语言记录，`.cfm` 是文件扩展名。原始 PLDB 快照不改，其他 CFML 实现/生态关系不在本批判断。
