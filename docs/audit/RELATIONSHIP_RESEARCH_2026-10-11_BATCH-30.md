# 关系研究批次 30：Gofer 的年代边界

日期：2026-10-11

核读 Hugs 98 User's Guide 官方/档案版本：

- URL：`https://www.chiark.greenend.org.uk/doc/hugs/users_guide/introduction.html`
- 完整响应 SHA-256：`27605e26edb7655284c72c1d2faf7bf5c2383e73e46971a2d5c8eba44b8617ae`
- 原文：“In September 1991, Mark Jones released a functional programming system called Gofer ... The system also included experimental type system extensions, many of which later became part of Haskell.”

结论：Haskell 报告把 Gofer 列为前驱，但 Gofer 首次公开发布晚于 Haskell 1.0（1990）。因此 `Gofer → Haskell` 只保留为报告方的总体历史回顾及后续 Haskell 版本/生态影响，不声称影响了 Haskell 1.0；原年代警告继续保留，不通过修改年份消音。
