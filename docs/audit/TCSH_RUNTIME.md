# tcsh 本机执行核验

2026-10-04，以已经安装的 `/bin/tcsh` 6.21.00 执行两份原创程序，不下载、不安装实现。版本查询为 `tcsh --version`，退出0。`/bin/csh` 与它指向同一文件；不能因此声称1978年的原始 C shell 已运行。

## 可复现方式

```sh
python3 scripts/verify-tcsh.py
```

脚本使用 `tcsh -f -n` 检查语法，再以 `tcsh -f` 执行；`-f` 跳过启动文件。每次调用最多10秒，程序仅使用变量、列表、控制结构和内建 echo。未安装 tcsh、语法检查失败、实际输出不符或无效语法未被拒绝时，不替换既有证据。成功后将程序、程序SHA-256、版本、命令、退出码、标准输出和错误保存到 [原始记录](../../data/audit/tcsh-runtime-checks.json)。

| 样例 | 范围 | 实际输出 |
| --- | --- | --- |
| arithmetic-loop | foreach、整数算术、变量引用 | `55` |
| list-condition | 列表、元素选择、if/then/endif | `Lisp` |
| invalid-syntax | 未配对双引号 | 退出1，`Unmatched '"'.` |

馆藏审计校验程序哈希、固定期望输出、语法和执行命令，以及无效语法的失败证据，再合并到本机执行统计。实际运行范围只覆盖这些样例，不证明完整符合性或所有历史 C shell 版本兼容。

## 实验台边界

tcsh 编辑器默认程序与 arithmetic-loop 原始记录逐字一致。Bash 和 Korn shell 的新默认程序也分别对应已有本机执行记录。浏览器检查逐项比对代码、核验编辑与返回时保留草稿、重置恢复原程序，并确认运行按钮禁用且没有模拟输出。

这些 Shell 示例可编辑并显示基础语法高亮，网页没有 Shell 运行环境。JavaScript/Python 仍是仅有的网页可执行语言；本机证据不会触发地图运行图标。
