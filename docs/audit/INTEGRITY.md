# 馆藏覆盖与关系完整性审计

本次审计基于项目保存的固定输入，运行 `npm run audit` 即可离线重生成证据清单及下列 CSV 和 JSON；仅运行完整性扫描可用 `python3 scripts/audit-integrity.py`。自动发现的名字、句子和时间冲突都是**复核线索**，不会自动升级成语言身份或历史关系。

## 1. 馆藏覆盖与身份

- [PLDB 固定快照](../../data/raw/pldb.snapshot.json)有 5,155 条记录，4,608 条被该来源标为语言。这是该快照的完整导入，不能推导出历史编程语言的完整收录。
- [GitHub Linguist 固定清单](../../data/raw/linguist.snapshot.json)来自提交 `76f88c6d3c22f8560d22d29854f24d9607f9edde`，原文件和 [MIT 许可](../../data/raw/linguist-LICENSE)一并保存。其 836 个文件语言/类型条目中，563 个标记为 `programming`。与 PLDB 对照有 402 个同名、1 个来源别名匹配、25 个可按 ID 猜测对应、135 个名称未匹配。逐项队列见 [linguist-crosscheck.csv](linguist-crosscheck.csv)。ID 猜测可能混淆不同语言，未匹配也可能是名称不同、方言/版本粒度不同、PLDB 缺条，或 Linguist 的文件类型分类不适合本馆；**不能把 135 当成已证实缺失语言数**。PLDB 自身也引用 Linguist 字段，这两个来源并非完全独立。
- HOPL [首页](https://hopl.info/)在 2026-09-25 显示其历史名录有 8,945 条语言。它与 PLDB 的口径不同，不能直接算覆盖率；页面同时声明不得复制或再发布内容，因此本项目没有搬运它的完整名录。PLDB 中有 1,808 条带 HOPL 链接，说明有可进一步逐项核对的出处，但不表示反向覆盖已核完。
- [identity-issues.csv](identity-issues.csv)列出 123 行同名或别名冲突审查线索，包括 2 条已人工确认的误别名。已将 PLDB 把 VBA 叫做 `vb6`、`visual basic 6` 的误别名从馆藏检索别名中排除，理由记录在 [alias-curation.json](../../data/audit/alias-curation.json)；原始快照未被修改。其他碰撞保留为待核，不自动合并。

## 2. 语言证据与可回溯性

- [全量证据清单](catalogue.csv)逐条保存分类、来源线索、审查状态、语法与实现证据、运行记录及下一步。来源字段只能提供线索；没有字段也不证明语言不存在。
- 77 条有人工审查记录；58 条标记为语法与实现文档已核，另有 7 条有历史一手资料。145 条标为已阅读的来源链接均保存 URL、页面内容哈希和摘录。自动检查这 58 条语言是否缺语法或实现文档审查，当前为 0 条缺口。文档核实不等于全部版本可执行，本机样例结果另见 [运行记录](../../data/audit/runtime-checks.json)及独立的 [ALGOL 60 记录](../../data/audit/algol60-runtime-checks.json)，合计 14 个语言样例通过、1 个 Lua 架构错误。ALGOL 60 的生成 C 警告与范围限制见 [核验说明](ALGOL60_RUNTIME.md)。
- 当前没有对 5,155 条逐条完成外部文档复核，也没有对所有历史语言的语法、实现和年代给出独立证明。全量 CSV 中的 `unreviewed` 必须保持待核。

## 3. 关系完整性

- [relationship-review.csv](relationship-review.csv)逐条列出 407 条规范化关系、两端、来源、依据、地图可见性与异常。336 条仅有 PLDB 记录字段及其记录页链接，**没有逐条的历史论证**；71 条人工补充有各自的引文说明和来源页面，其中部分保留页面哈希。脚本只检查来源/说明是否存在，不替人评判文献内容。 页面关系卡片显示「附有论证与出处」或「来源字段，关系待核」，后者在地图中较淡；前者不代表全部历史论证已完成。另有 7 条独立校验的[生态关系](../../data/ecosystem-relations.json)，不计入此表。
- 年代先后有 4 条异常线索，关系端点有 13 条涉及来源未标为语言的项目。这两类需要检查年代口径和对象分类，不能直接删除。
- 231 个地图节点中有 152 个在全馆没有任何已记录规范化关系；另有一些只连向地图外条目。按地图两端都可见计算，173 个节点没有规范化关系连线。[map-isolates.csv](map-isolates.csv)、[逐节点关系表](map-lineage-review.csv)与 [50 个常显标签关系表](label-lineage-review.csv)供逐个判断是历史源头、缺失关系，还是数据/分类问题；孤立不等于没有上游。[地图关系复核说明](MAP_LINEAGE.md)列出本轮已核关系与候选初筛。
- [relationship-candidates.csv](relationship-candidates.csv)从快照中的 `derived from`、`successor to` 等语句抽出 185 条尚未收录的候选。它们是二手描述的自动匹配，可能误识别，不能直接画到图上。`wikipedia_related` 等普通相关链接没有用来推断影响关系。

## 下一轮复核顺序

1. 处理 25 个 ID 对应猜测、135 个 Linguist 名称未匹配项和 123 行身份冲突，记录每个结论的来源、别名/版本判断及理由。继续接入有明确再利用许可的其他历史目录，才能讨论跨目录覆盖率。
2. 按 [逐节点关系表](map-lineage-review.csv)复核 173 个地图无规范化关系可见连线节点，优先处理 [当前常显标签缺口](MAP_STATUS.md)、地图候选、4 条年代异常与 13 条跨分类端点；每条新增连线注明确切含义、原文依据和年份口径。
3. 对 336 条只有字段级出处的关系逐条补强或降级为待核；对 154 个全馆孤立节点逐项记录“已核源头”或“上游待查”，不把空白解释为无关系。

机器可读汇总见 [integrity-summary.json](integrity-summary.json)。本次审计提高了**缺口的可见性**，尚不能宣称馆藏或关系已基本穷尽。
