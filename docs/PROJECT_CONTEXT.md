# Code Museum · 产品上下文与交接

整理于 2026-09-24，更新于 2026-10-05，依据项目讨论及当前源码。本文是上下文摘要，不是完整聊天记录，也不是所有讨论项均已实施的承诺。构建方法见 [README](../README.md)。

## 1. 我们在做什么

一个可游览、检索并逐步接入编程体验的在线编程语言博物馆，不是实体馆、热门语言榜或某门语言的宣传站。

- 用户希望中文可用，并有国际化空间；当前界面主要为中文，完整多语言机制尚未实现。
- 最终希望包含语言的写法、规则、编辑、编译与运行；曾明确提出基于 WebAssembly 的运行引擎。这是产品目标，不是当前已有后台。
- 用户明确要求完整语言索引，而不是“以后可扩展”的小型主流列表。这个要求应持续推动馆藏研究；同时必须诚实标注实际覆盖边界，不能把某个来源的全量快照说成人类所有语言。
- 要能从当代追溯到早期编程与计算构想。用户提到的 Ada 是 Ada Lovelace，不是仅指 Ada 语言；人物、机器、计算理论与语言应区分建模。

## 3. 视觉方向与交互意图

讨论从“语言家谱树”发展为可分叉、可汇流的“语言演进长河”。早期也尝试过带枝叶的神话古树；用户要求简化神话装饰、突出历史叙事，后来明确转向河流。

- 要一条看得出来、带浪花、有尺度感的大河，不是几根关系曲线，也不是类似售楼处小区水系图的装饰。
- 河道可以分流与汇流；但河景是历史意象和导航背景，不能把每条视觉支流包装成有史料支持的语言演进。
- 方位明确：当前为西侧源流到东侧当代；时间位置非等距。早期序厅是叙事排布，不是精确时间轴。
- 点击语言要能进入档案、查看并追溯上下游。用户也期待点击后的展开效果；当前有详情面板与关系高亮，不要据此声称复杂展开动画已经完成。
- 用户反复反馈字号过大、缩小不明显，偏好克制的文字尺度；介绍文案有意境即可，不要生硬说教或靠换文案冒充视觉改进。
- 用户对后期河景版本反馈“很帅”。本次结构重构保留了该版页面与插画；后续不要无故推倒重做。

“长河落日圆，欲穷语言树，到此不需还”表达的是可探索、能追根溯源的整体体验，不是要求把这句话固定为页面标题。

## 4. 历史准确性与馆藏要求

用户明确质疑过 Java、C++、Smalltalk 的关系呈现，以及众多语言和流派缺席的问题。这不是只补几个名字就结束的需求。

- 不能把语言影响关系简化成单亲血缘树。区分语法借鉴、思想影响、超集扩展、实现关系等概念；规范化历史关系支持 `influencedBy`、`successorOf`、`supersetOf`、`implementationOf` 和 `compatibleWith`；独立生态关系支持 `extensionInterface`、`hostRuntime` 和 `interop`。每条关系仍需独立核实。
- Java 与 C/C++ 有明确的词法、语句等影响，不能直接等同于 C++ 的派生版本或超集。Smalltalk 的上游不能留成“凭空出现”；当前已有 Simula、Lisp 的带出处补充。
- Java → C# 作为语法与设计影响关联录入，依据 Microsoft C# 规范导言中的 Java 读者定位；这条关系不表示 C# 是 Java 派生语言或两者运行时兼容。
- Java → Scala 与 Java → Groovy 依据 Scala、Groovy 官方教程和语言说明录入为语法与设计影响；JVM 互操作本身不能推导出超集或严格的前后继承。
- Rust 官方 Reference 的影响清单明确列出 C++、OCaml、Haskell、Erlang、Scheme、C#、Ruby 的具体设计输入，已逐条补为设计关系。Python 与 C/C++ 的 CPython 扩展接口、Java 的 Jython 平台实现、Rust 的 PyO3 工具互操作，以及 Rust 与 C 的 FFI，归入单独的生态层；这些不表示 Python 或 Rust 继承了对应语言。
- Objective-C → Swift 依据 Swift 官方关于命名参数设计承接的说明录入；Ruby 官方列举的 Perl、Smalltalk、Eiffel、Ada、Lisp 影响也已逐条录入。它们均表示设计影响，不表示严格的语言继承或源码兼容。
- BCPL → B → C 的历史承继已作为两段 `influencedBy` 关系录入，依据 Dennis M. Ritchie 的 C 语言发展论文及 Bell Labs B 语言手册。图中用虚线表达影响/演进，不表示严格的超集或源码兼容；BCPL 是 C 的间接前身。
- BASIC → Visual Basic 的家族演进、Visual Basic → VBA 的 Office 版本分支、VBA → VBScript 的脚本子集关系已分别按微软资料录入；BASIC → Visual Basic 的来源是微软平台刊载的二手历史概述，后两条有微软产品文档直接说明。2026-10-03 补核微软语法及宿主资料后，VBA 与 VBScript 已入主图，原有两段关系可在地图追溯；不宣称各宿主程序可直接互跑。
- 用户点名的覆盖检查包括：汇编、Fortran、BASIC、PL/SQL、FoxPro、R、MATLAB，以及函数式编程分支。还应系统关注早期语言、小众语言和不同应用领域，不只顾当前热门生态。
- “没有记录”不等于“没有历史关系”。年代可能对应设计、首次实现、首次发布或具体版本，不能未经核查混用。
- 普通相关链接不是影响关系证据；优先查原始设计文献、标准、作者叙述，保留出处和不确定性。
- 将全馆检索与地图显示密度分开处理：地图可以分层、缩放、按需标注，但不能因此从馆藏索引中删掉非主流语言。

## 5. 当前已实现的基线

截至整理时，源码与构建具备：

- 地图提供共享模糊搜索框，范围为当前有年代的地图节点，匹配名称、别名和馆藏 ID，并支持轻微拼写错误；保留 C++ 与 C# 的符号区别。结果可点击或用方向键/Enter 选择，直接定位、高亮并打开档案。谱系未显示的语言标注「仅时间长河」，选中后切到时间长河；无匹配时可携带查询进入全量馆藏检索。

- 纯 HTML/CSS/JavaScript 静态页面；时间长河、关系谱系、语言检索、语言实验台、出处说明以五个页签切换，共享单屏主展示区；页面框架不纵向滚动，地图默认适屏并可放大，检索列表与出处内容在各自面板内滚动。河景插画、水流与浪花动画、年代刻度仍保留。
- 固定 PLDB 快照的 5,155 条记录，其中来源标记为语言的 4,608 条。来源的语言标记覆盖较宽；主图目前筛入有语法/代码示例及编译器、解释器线索，或已人工核实的 233 个节点。记法、产品、工具与指令集经过分类过滤，少数确有可执行语法的领域语言保留，人工决定记在 `data/audit/map-curation.json`。目录分成 233 条已核与有线索语言、3,698 条性质待核、1,224 条相关技术或形式/数据语法；原始记录仍可在全馆入口检索。规范化历史关系共 417 条，另有 7 条独立校验的生态关系。
- 全量馆藏检索、证据分层筛选、名称/年代排序、分页、详情、上下游点击跳转与来源入口。人工审查过的条目会显示审查结论与来源；来源自称语言不自动获得已核语言标签。
- 地图默认显示有年代且具有语法/代码示例与执行环境线索，或已经人工核实的语言节点，部分语言显示文字，其余为微光点；其余馆藏仍可由完整目录访问。当前 50 个常显标签由 TIOBE 2026 年 9 月前 50 名中已入图的 39 个、10 个有出处的历史叙事节点，以及 Groovy 关系阅读例外组成。TIOBE 是当下关注度参考；历史锚点有史料依据，但不能称为历史热度排名。详见 [标签选择说明](audit/LABEL_SELECTION.md)。不要声称全馆每条记录都有精确地图坐标。
- 全景图可切换“时间长河”和“关系谱系”：前者按来源年代定位，默认适屏显示整个时间范围，放大后可在地图区域内浏览；后者按设计关系层级排列。两种图都可切换「设计脉络」与「实现与生态」连线，生态关系不影响谱系深度。谱系图不包含未记录关系的全部馆藏，其他条目仍由完整目录检索；不得把该图称为完整血缘树。
- 点选有关联记录的语言后，高亮其可追溯的上游与下游标签、关系线，其余地图节点弱化并轻微虚化；聚焦时把已记录上游与直接下游尽量留在可视范围内。点选没有关系记录的条目时，仅突出当前标签并弱化其他节点，不绘制推测关系；点击地图空白处恢复适屏全景。
- 详情栏在宽屏与主展示区并排，打开时缩窄地图或检索区域，关闭后恢复；窄屏将详情放在主区域下方并压缩主区域，不遮挡地图。分隔条可拖动或用方向键调整宽度、窄屏高度，并在本机保存尺寸；详情打开时顶部简介收紧。地图聚焦按变化后的实际可视区域重新定位。
- 详情打开后，地图优先将选中语言置于可视区中央偏右，同时尽量容纳已记录上游与直接下游。悬停或键盘聚焦详情中的关系条目，会临时突出对应地图节点和关系线；目标超出可视区时临时平移地图，离开后恢复原位置。只有当前地图中有对应节点和连线时才执行联动。
- 聚焦取景优先容纳选中节点与直接相连的上游、下游，并给文字标签预留边距；聚焦连线、虚线间距和命中区域按地图 CSS 缩放比例补偿，避免缩小后关系难辨认；更远层的关系仍高亮，但不挤走直接关联节点。跨越过大的关系可由详情中的关系条目临时平移查看。
- 地图微光点悬停或键盘聚焦时立即显示名称；不依赖浏览器原生 `title` 提示的延迟。微光点位于普通标签上方，保留 7 像素视觉尺寸并使用 20 像素点击区域。密集点位点击后列出附近语言供精确选择。点选后的黄色名称标签仍持续显示。详情中的关系标注「当前地图有连线」或「仅档案记录」，方便区分地图可见关系与馆藏记录。
- 河景插画与动态水纹已弱化，用于衬托语言节点和关系连线；动态水纹按原始插画的 1536 × 1024 坐标沿可见河段手工布置，不再用贯穿陆地的统一波浪线；虚线动画按完整图案周期单向循环，浪花只改变明暗，不左右往返。河道仍是历史意象，不作为史实关系。
- 序厅包含 Jacquard、Babbage、Ada Lovelace、Church / Turing 相关事件；它们不作为所有语言的直接祖先。
- 当前关系未逐条完成一手史料复核。馆藏全量是“这一版 PLDB 快照全量”，不是历史研究已完成。
