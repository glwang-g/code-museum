# 独立本地版式预览

完整正式改版另在`src/`完成；本目录继续保留方案A对照，原版由固定`archive/classic-ui/`重建，实验目录不作为正式业务控制器。

这是供比较和讨论的独立设计目录，不替换当前应用入口，也不随普通网站构建发布。当前网站源码保持原样；新版文件在 `experiments/modern-preview/`，本地服务在 `scripts/preview-modern.cjs`。两种版式可以同时打开。

```sh
npm run modern:preview
```

- 新版首页：<http://127.0.0.1:4188/>
- 新版馆藏：<http://127.0.0.1:4188/#collection>
- 新版实验台：<http://127.0.0.1:4188/#lab>
- 完整原版：<http://127.0.0.1:4188/classic/>

服务只监听本机回环；在启动终端按 Ctrl+C 可停止。默认端口4188，可用 `MODERN_PREVIEW_PORT` 改端口。命令先从固定源码离线构建原版数据，再启动独立版式服务；没有新增依赖或构建时在线下载。文件读取即生效，改CSS/JS后刷新页面即可。

## 本轮设计

暖白/墨绿为主，深色主题可切换。导航收敛为探索、馆藏、实验台；探索内有精选导览、按来源年代组织的时间长河和带来源的设计关系列表。首页局部关系图只连接已记录的边，不能据此推断完整影响范围。全量馆藏5155条、语言4608条保留，支持名称/别名/创造者搜索、全半角归一、筛选及分页；语言档案连接历史、规则、来源、关系和代码示例。5条既有导览及同题代码比较读取原资料。

实验台默认约六成宽编辑器、四成宽反馈，运行结果和检查讲解切换显示。运行与检查按钮放在同一个工具区，手机也可直接触达；手机点击后带到反馈区域。程序输入按需展开，导入/下载/恢复保留。新版草稿和主题使用独立浏览器存储键，不读取或覆盖原版草稿。

## 已接通与保留边界

- 复用原版固定 JavaScript、Python、Lua、Scheme Worker，按点击真实执行；独立Worker、输出限制、加载/运行超时、停止、切换/后台取消保留。没有重建或替换既有语言执行器。
- 原版 `lab-explanations.js` 的三种判断、返回校验、快照绑定、缓存、纠错候选核对和原稿保护直接复用；固定示例讲解也读取原资料。红绿反馈跟随现有判断，编辑后清除。
- 默认没有连接远端执行和模型服务。远端语言可编辑原示例，但运行时明确显示环境未连接；模型检查请求返回诚实的未接入提示，不显示伪造结果、不读取 `.env.deepseek.local`、不自动花费模型额度。
- 如以后需要与已有本机后端联调，可显式设置 `EXECUTOR_UPSTREAM` 或 `MUSEUM_EXPLANATION_UPSTREAM`；只接受本机HTTP地址，由原预览代理校验。此预览尚未实现远端提交/排队/取消界面，不能据代理配置声称远端端到端接入完成。
- 原版仍通过独立路径完整提供；页眉、页脚和档案内都有相关入口。正式站点、Git提交及部署没有变更。

## 核验

先保持本地预览服务运行，再执行：

```sh
node experiments/modern-preview/check-browser.cjs
```

检查使用独立Chrome资料目录。验证真实固定数据、搜索/分页、档案/出处、导览/关系/比较、四种浏览器真实输出、JavaScript错误/超时/停止、草稿刷新恢复、缺失按下事件的单击兼容，以及1440/900/390/320明暗布局。模型状态使用明确拦截的显示夹具，另检查一次本机503未接入响应；不调用真实模型或生产执行器。报告为 `data/audit/modern-preview-browser.json`，截图位于忽略的 `tmp/modern-preview/browser/`。验收工具支持可选本地 `origin/ready`，原有检查默认行为保持不变。
